# Technology Vendor Management Overview

**Document Classification:** Internal — Procurement & Engineering  
**Last Updated:** August 2026  
**Owner:** Engineering Operations

## Overview

Northstar Technologies maintains strategic partnerships with a curated set of technology vendors who provide commercial support, consulting, and professional services for the open-source and proprietary technologies used across the Engineering Department. This document summarizes the current vendor landscape and support arrangements for each major technology in use.

## Database & Storage Technologies

**Neo4j** is supported by GraphSphere Technologies, a boutique consulting firm specializing in graph database architecture, performance tuning, and enterprise deployment. GraphSphere provides Northstar with dedicated support engineering, quarterly health checks, and priority access to Neo4j platform upgrades. The AI Platform Team is the primary consumer of Neo4j through Project Atlas.

**PostgreSQL** is supported by DataBridge Systems, a managed database services provider with deep expertise in PostgreSQL administration, replication, and disaster recovery. DataBridge provides 24/7 production support, automated backup verification, and migration consulting for Northstar's PostgreSQL deployments. The Payments Platform Team relies on this partnership for Project Ledger's database operations.

**Redis** is supported by CacheWorks Ltd, a specialized vendor focused on in-memory data store solutions. CacheWorks provides Northstar with Redis cluster management, capacity planning, and performance optimization services. The Core Services Team leverages this support for the Authentication Gateway's session and token caching infrastructure.

## Streaming & Messaging

**Kafka** is supported by StreamForge Solutions, a distributed systems consulting firm with expertise in Apache Kafka deployment, monitoring, and stream processing architectures. StreamForge assists Northstar with Kafka cluster sizing, consumer group optimization, and disaster recovery planning. Project Ledger is the primary consumer of Kafka within the organization.

## Frameworks & Languages

**FastAPI** is supported by APIForge Consulting, a Python web framework consultancy that provides training, code review, and architectural guidance for teams building high-performance API services. The AI Platform Team engages APIForge for periodic performance audits and best-practice reviews on Project Atlas's API layer.

**Python** is supported by DevTools Partners, a developer tooling and language ecosystem consultancy. DevTools Partners provides Northstar with Python version migration support, dependency management consulting, and developer productivity tooling. Multiple teams across the Engineering Department benefit from this partnership, with the Payments Platform Team's Fraud Detection Service being a primary consumer.

## Vendor Governance

All vendor relationships are reviewed annually by the Engineering Operations team in coordination with Procurement. Contracts include standard SLA commitments, data handling agreements, and escalation procedures aligned with Northstar's enterprise security requirements.
